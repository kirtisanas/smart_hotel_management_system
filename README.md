# Smart Hotel Management System

A web-based hotel management system developed using PHP and MySQL to manage hotel users, rooms, and bookings.

## Features

* User registration and login
* Room management
* Room booking management
* Booking records
* MySQL database integration
* Web-based hotel management interface
* Simple and user-friendly interface

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP
* MySQL Workbench
* VS Code

## Project Structure

```text
smart_hotel/
├── PHP files
├── CSS/
├── JavaScript/
├── images/
└── database files
```

## Database

The project uses **MySQL** for storing application data such as:

* Users
* Rooms
* Bookings

The project was developed and tested using **XAMPP** as the local development environment.

## How to Run Locally

1. Install XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Copy the project folder into:

```text
C:\xampp\htdocs\
```

4. Create a MySQL database named:

```text
hotel_booking
```

5. Import the project's database file if provided.
6. Update the database connection settings in the PHP configuration file.
7. Open the project in your browser:

```text
http://localhost/smart_hotel/
```
